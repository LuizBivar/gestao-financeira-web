3 · Segurança e limites

Antes de cada gravação, o aplicativo exige uma cópia confirmada da versão anterior; depois compara novamente o arquivo original. Se houver mudança externa, bloqueia o salvamento para evitar sobrescrita silenciosa. Não existe sincronização direta via Microsoft Graph, bloqueio transacional entre computadores, criptografia, OCR ou recuperação automática. O OneDrive pode atrasar a sincronização ou criar cópias de conflito.

Compatibilidade: acesso direto ao arquivo requer a API File System Access (em geral Chrome/Edge no desktop). Navegadores sem suporte podem usar abertura JSON e baixar cópia, mas não salvar sobre o arquivo original.

4 · Diagnóstico local (sem alterar arquivos)

Executa verificações em memória com dados inteiramente fictícios. Não substitui os testes reais de permissões, cancelamento e sincronização no OneDrive.
